# 主题色

VitePress 的主题色彩应用于按钮、代码标签指示条、链接、首页标题、搜索结果高亮等位置，由下述变量决定．

这些变量及其应用场景列举如下，

- `--vp-c-brand-1`，应用于部分页面组件与文字，例如代码组激活标签指示条、行内代码文字、正文链接等．
- `--vp-c-brand-2`，应用于部分文字在悬停状态下的颜色，例如正文链接等．
- `--vp-c-brand-3`，应用于首页横幅中的主题色按钮默认状态背景色．
- `--vp-c-brand-soft`，应用于部分页面组件与文字的高亮背景色，例如提示容器及其内部行内代码元素等．

主题以 CSS 颜色 `rgb(64, 124, 233)` 作为色彩基准，在 OKLCH 色彩空间中寻找一组色相相同的颜色．

依据《Web 内容无障碍指南》[^1]，约定按如下约束求解在浅色与深色主题上的颜色系列．

作为文字时，

- `--vp-c-brand-1` 与页面背景颜色对比度至少为 4.5:1．
- `--vp-c-brand-2` 与页面背景颜色对比度至少为 4.5:1．

作为底色时，

- `--vp-c-brand-1` 作为搜索高亮文字底色时，与文字颜色对比度至少为 4.5:1．
- `--vp-c-brand-soft` 作为提示容器与行内代码文字底色时，与文字颜色对比度至少为 4.5:1．

作为指示元素时，`--vp-c-brand-1` 与相邻背景的对比度至少为 3:1．

此外，主题色按钮的三种状态底色，即，

- 默认状态：`--vp-c-brand-3`，
- 悬停状态：`--vp-button-brand-hover-bg`，
- 激活状态：`--vp-button-brand-active-bg`，

须满足这些约束，

- 默认状态下，底色与文字颜色对比度至少为 4.5:1．
- 默认、悬停与激活状态下，底色与页面背景颜色对比度至少为 3:1．
- 彼此之间存在至少 0.05 的 OKLCH 色彩空间明度差．

由于悬停与激活的时间较短，不作这两种状态下按钮颜色与文字颜色的对比度要求．

[^1]: World Wide Web Consortium. (2024, December 12). _Web Content Accessibility Guidelines (WCAG) 2.2_. https://www.w3.org/TR/2024/REC-WCAG22-20241212/
