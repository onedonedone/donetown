# 中性色

VitePress 的中性色彩应用于页面背景、边框、分隔线与文字等位置，由下述变量决定．

这些变量及其应用场景列举如下，

- `--vp-c-bg`，应用于页面、导航栏，与本地搜索框等元素的背景．
- `--vp-c-bg-alt`，应用于侧边栏、默认代码块与输入框的背景．
- `--vp-c-bg-elv`，应用于下拉菜单等浮层的背景．
- `--vp-c-bg-soft`，应用于首页特性卡片、表格偶数行、代码复制按钮等的背景．
- `--vp-c-border`，应用于输入框等控件的边框．
- `--vp-c-divider`，应用于表格边框、引用块左侧竖线、水平分隔线，以及侧边栏与菜单中的分隔线．
- `--vp-c-gutter`，应用于代码块内的分隔线，以及导航栏、页脚等布局区域之间的分隔．
- `--vp-c-text-1`，应用于正文与标题．
- `--vp-c-text-2`，应用于次要文字，例如页面目录、侧边栏条目、前一页与后一页笔记的跳转链接等．
- `--vp-c-text-3`，应用于更次要的文字与图标，例如输入框占位文字、侧边栏折叠箭头、外部链接图标等．

深色主题的色彩搭配沿用自 GitHub Primer 设计系统 7.10.0 版本 Dark Dimmed 色板，即 Visual Studio Code 主题 GitHub Dark Dimmed 所用的方案．

浅色主题的色彩搭配以 VitePress 默认浅色主题为基准，将页面背景由 `rgb(255, 255, 255)` 改为 `rgb(245, 245, 245)`，其余颜色在保持 OKLCH 色相与彩度不变、与页面背景的对比度不变的约束下，降低明度，得到新的颜色．
