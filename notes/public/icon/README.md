# 图标的视觉设计

图标文字取自 $`\TeX`$ 数学公式 $`\mathrm{d}t`$，对应项目名称 donetown 中两个组成部分的首字母．字形由 MathJax 4.1.3 渲染，使用 New Computer Modern 字体．

在应用中，图标会以不同大小显示，例如，用作浏览器标签页图标，或是网页导航栏图标．不同大小的字形需要不同设计，这是字体学通行的原则之一．小字形往往需要相对更粗的笔画，笔画宽度相对于字框的比例更大，这样才能获得与较大字形相近的视觉辨别效果[^1]．因而，较小字号的字形并非大字形的简单缩小，必须另作设计．

这份笔记详细记录了为适应不同尺寸而对图标所作的修改．

矢量图文件约定，绘制图片所用的二维坐标系是一个大小为 $`1500 \times 1500`$ 的正方形．无论图片最终是否被缩放或拉伸、以何种尺寸显示，所有设计时引用的坐标与长度都定义在这一坐标系中．

## 形态学膨胀与间距调整

给定平面上的一个区域 $`D`$ 与正实数 $`r`$，以半径 $`r`$ 对 $`D`$ 作**形态学膨胀**<sub>（Morphological Dilation）</sub>，意味着，按如下方式获得一个新的区域，

```math
D^{(r)} = \{ \, \boldsymbol{p} : \exists \, \boldsymbol{q} \in D, \, \lVert \boldsymbol{p} - \boldsymbol{q} \rVert \leqslant r \, \}.
```

直觉上，这一过程可以理解为，将一个半径为 $`r`$ 的圆沿 $`D`$ 的轮廓滚动一圈．其覆盖过的所有区域与区域 $`D`$ 的并集便是膨胀后的结果．

形态学膨胀增加了字形笔画的面积，同时也减少了字形周围的留白区域，相邻字形之间的空白间距随之缩小．为了确保视觉辨别的效果，设计者必须为较小的图标设置相对更大的字形间距．为小尺寸字形设置的额外间距记作距离 $`\Delta{t}`$．

在应用设计中，膨胀半径 $`r`$ 与额外间距 $`\Delta{t}`$ 分别设置如下，

- 全尺寸图片 `dt-full.svg` 使用 $`r = 25`$ 与 $`\Delta{t} = 10`$，软链接至 `dt.svg`．
- 导航栏图标 `dt-24px.svg` 使用 $`r = 35`$ 与 $`\Delta{t} = 35`$，栅格化为 `dt.png`．
- 标签页图标 `dt-16px.svg` 使用 $`r = 45`$ 与 $`\Delta{t} = 75`$，栅格化为 `dt.ico`．

## 凸包与视觉中心

MathJax 所渲染的数学公式 $`\mathrm{d}t`$ 被放置在一个大小为 $`917 \times 705`$ 的字框中．此时，将字框的中心与 $`1500 \times 1500`$ 画布的中心对齐，是最简单、直接的居中方式．然而，字框的中心并不总是与人眼感知的视觉中心一致．

为了获得更接近视觉感受的中心位置，图标采用字形**凸包**<sub>（Convex Hull）</sub>的面积重心作为视觉中心．凸包是包含所有字形轮廓点的最小凸多边形．面积重心则是将凸包视为均匀密度的平面区域时的质量中心．与矩形字框的中心相比，凸包的面积重心降低了窄长结构对中心位置的影响，能够更好地反映字形笔画的实际分布．

计算时，先沿着两个字形的轮廓路径采样，应用 Andrew 单调链算法求出凸包，再用多边形重心公式求出面积重心．最终的图标文件以凸包的面积重心为视觉中心，将字形居中放置在 $`1500 \times 1500`$ 的画布上．

在应用中，不同尺寸字形的面积重心分别如下，

- 全尺寸图片 `dt-full.svg` 的面积重心为 $`(484.8, \, -313.6)`$．
- 导航栏图标 `dt-24px.svg` 的面积重心为 $`(497.1, \, -313.9)`$．
- 标签页图标 `dt-16px.svg` 的面积重心为 $`(516.9, \, -314.5)`$．

## 主题色与图标背景色

站点以 OKLCH 色彩空间中色相为 $`261^\circ`$ 的色彩为主题色．

图标的底板需要在浅色与深色两种主题下都保持足够的辨识度．设计的目标是找到一种颜色，使其在深色 `#22272e` 与浅色 `#f5f5f5` 两种主题背景色上的对比度相等．

依据《Web 内容无障碍指南》[^2]，需要先由线性色彩值的加权和计算出颜色的亮度 $`l`$，

```math
l = 0.2126 \cdot r^* + 0.7152 \cdot g^* + 0.0722 \cdot b^*.
```

这里，线性色彩值由每个色彩通道上的归一化值 $`v`$ 经如下的传递函数计算得到，

```math
v^* = \left\{
    \begin{aligned}
        & \dfrac{v}{12.92} \,, & v \leqslant 0.04045 \,, \\
        & \left( \dfrac{v + 0.055}{1.055} \right)^{2.4}, & v > 0.04045 \,,
    \end{aligned}
\right. \qquad v \in \left\{ \dfrac{r}{255}, \dfrac{g}{255}, \dfrac{b}{255} \right\}.
```

当两种颜色的亮度分别为 $`l_1`$ 与 $`l_2`$ 时，对比度为

```math
\mathrm{Contrast}(l_1, l_2) = \dfrac{\max(l_1, l_2) + 0.05}{\min(l_1, l_2) + 0.05} \, .
```

设目标亮度为 $`l_*`$，浅色背景 `#f5f5f5` 的亮度为 $`0.913`$，深色背景 `#22272e` 的亮度为 $`0.0199`$，令目标颜色与两个背景之间的对比度相等，

```math
\frac{0.913 + 0.05}{l_* + 0.05} = \frac{l_* + 0.05}{0.0199 + 0.05} \,,
```

解得 $`l_* = 0.209`$，此时两个方向的对比度均约为 $`3.71:1`$．

在 OKLCH 色彩空间中，先固定主题色的彩度与色相不变，用二分法求出使亮度等于 $`l_*`$ 的明度，得到图标的背景颜色 `#3f7be8`．离散化后，该颜色与浅色背景 `#f5f5f5` 的实际对比度为 $`3.697:1`$，与深色背景 `#22272e` 的实际对比度为 $`3.727:1`$．

字形的填充色与描边色均为纯白色 `#ffffff`．
